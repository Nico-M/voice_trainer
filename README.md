# Voice Trainer

一个基于 `React + Vite + TypeScript + Material UI + Tone.js` 的移动端练声原型项目。

项目当前重点是提供一个适合手机使用的音阶练习界面：上方选择练习与速度，下方使用 `Canvas` 渲染漫画风钢琴键盘，并通过采样钢琴音色完成播放与手动试音。

## 项目特点

- 面向移动端的单页练声界面
- 基于 `Tone.Sampler` 的钢琴采样播放
- 支持多组预设音阶练习
- 练习开始前由用户自己选择起始音
- 支持 `单次循环 / 自动上行 / 自动下行` 三种播放模式
- 支持 `50 - 140 BPM` 的速度调节
- 键盘使用 `Canvas` 绘制，支持顶部预览条拖动视窗
- 自动播放时，当前音符会自动保持在可视范围内
- 每个键位显示音名与唱名，便于练声和识音

## 当前功能

### 1. 音阶练习

当前内置了 7 组音阶练习，配置位于 `src/config/voiceTrainerExercises.ts`。

每条练习都包含：

- 练习名称
- 音高步骤
- 节拍时值
- 展示用描述文本
- 启动方式与分类

### 2. 起始音选择

音阶练习不会在选中后立刻自动播放，而是会先进入“待命”状态。

用户需要在下方钢琴键盘上按下一个起始音，系统才会从这个音开始执行当前练习。这样更符合练声场景，不会强制从固定音高开始。

### 3. 播放模式

当前支持三种模式：

- `单次循环`
- `自动上行`
- `自动下行`

自动上行和自动下行会在每轮练习结束后，把起始音按半音向上或向下移动，再继续下一轮，直到超出可播放范围。

### 4. 速度控制

页面提供 `BPM Slider`，可直接调节练习速度。当前速度会实时影响：

- 每个音的步长
- 每个音的实际持续时间
- 每轮练习之间的间隔

### 5. 漫画风钢琴键盘

键盘组件位于 `src/components/MangaPiano.tsx`。

主要特性：

- 使用 `Canvas` 绘制 88 键钢琴
- 顶部预览条显示完整键盘范围
- 通过拖动预览条移动当前视窗
- 自动播放时自动跟随当前音符
- 白键和黑键均显示音名与唱名
- 支持手动按下和抬起发声

## 技术实现

### 核心依赖

- `React 19`
- `Vite 7`
- `TypeScript 5`
- `Material UI 7`
- `Tone.js`

### 目录说明

`src` 目前按职责分组：

- `src/components`
  页面组件与可视化组件
- `src/hooks`
  播放状态机与采样器生命周期管理
- `src/utils`
  纯计算与播放辅助函数
- `src/audio`
  音频播放封装
- `src/config`
  练习配置与采样映射配置
- `src/assets/piano`
  钢琴采样音频资源

### 关键文件

- `src/App.tsx`
  页面入口与布局组装
- `src/hooks/useManagedPlayer.ts`
  `TonePlayerAdapter` 生命周期管理与注入
- `src/hooks/useExercisePlayback.ts`
  练习播放状态机
- `src/audio/sampler.ts`
  对 `Tone.Sampler` 的封装
- `src/audio/tonePlayerAdapter.ts`
  H5 播放执行器与事件回调

```bash
npm run dev
```

## 使用方法

### 基本流程

1. 打开页面
2. 在顶部下拉框中选择一个音阶练习
3. 根据需要调整 `BPM`
4. 点击模式按钮切换播放模式
5. 在下方钢琴键盘上按下一个起始音
6. 系统从该音开始执行当前练习

### 手动试音

如果当前没有待命中的练习，直接按下键盘会触发手动发声，松开后停止。

### 停止播放

点击顶部的“停止”按钮即可中断当前播放，并释放残留音。

## 配置说明

### 练习配置

练习数据位于 `src/config/voiceTrainerExercises.ts`。

其中：

- `interval` 表示相对起始音的半音偏移
- `beats` 表示该音持续多少拍
- `desc` 仅用于界面展示，不参与实际播放计算

例如：

- `0` 表示当前起始音
- `4` 表示大三度
- `7` 表示纯五度
- `12` 表示高八度同名音

### 采样映射

钢琴采样映射位于 `src/config/noteMapping.ts`。

音频封装会通过 `import.meta.glob` 解析 `src/assets/piano` 中的采样资源，并交给 `Tone.Sampler` 使用。
